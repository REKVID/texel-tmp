## Краткий вердикт

Платформа в **рабочем, относительно стабильном состоянии**. Все основные подсистемы реализованы и связаны: фронт, бэкенд, AI-чат, новости, авторизация, админка, обучение и Vibe Coding. Большая часть архитектурных решений уже принята и зафиксирована в `docker-compose.yml`. Платформа готова к локальному запуску и демонстрации, но это **учебный проект**, а не production-сервис.

---

## Что работает

| Подсистема | Статус |
|---|---|
| Frontend (React + Vite + TS) | Работает, есть все основные страницы (`/`, `/training`, `/training/:id`, `/training/:id/test`, `/vibe-coding`, `/profile`, `/settings`, `/admin`). |
| Backend API (Express + SQLite) | Работает на порту `3001`. Реализованы регистрация, вход, сессии, профиль, тесты, админ-CRUD. |
| AI-чат (FastAPI + OpenRouter) | Работает на порту `8001`. Использует авто-маршрутизатор `openrouter/free`, ключ из `.env`. |
| News-сервис (Express + RSS) | Работает на порту `8002`, тянет хаб Habr `artificial_intelligence`. |
| Авторизация | Полная: bcrypt-хэши, httpOnly-сессии, валидация через `zod`, защита админ-эндпоинтов. |
| Роли | Две роли (`user`, `admin`), серверный и клиентский guard'ы. |
| Админ-панель | Список / редактирование / удаление пользователей; защита от самоудаления. |
| Темы и язык | Сохраняются в `localStorage` (тёмная/светлая/системная, RU/EN). |
| Vibe Coding (IDE) | Monaco + iframe sandbox для HTML/JS/CSS, Pyodide для Python в браузере. |
| Docker Compose | Поднимает все 4 сервиса одной командой. |
