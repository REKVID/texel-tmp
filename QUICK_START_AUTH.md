# 🚀 Быстрый старт - Система авторизации Telegram

## За 5 минут - полная работающая система!

### Шаг 1: Настройка БД (30 сек)

```bash
# Создайте базу в phpMyAdmin или командой:
mysql -u root -p -e "CREATE DATABASE texel_learning CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# Импортируйте схему:
mysql -u root -p texel_learning < ai-chat-microservice/database_schema.sql
```

### Шаг 2: Backend (1 мин)

```bash
cd ai-chat-microservice

# Скопируйте .env.example в .env и отредактируйте
cp .env.example .env
# Отредактируйте в редакторе:
# - DB_PASSWORD - ваш пароль MySQL
# - TELEGRAM_BOT_TOKEN - токен от BotFather (или оставьте пусто для демо)
# - JWT_SECRET_KEY - ваш секретный ключ

# Установите зависимости
pip install -r requirements.txt

# Запустите сервер
python run.py
```

Сервер запустится на `http://localhost:8001`

### Шаг 3: Frontend (1 мин)

```bash
# В корне проекта
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`

## 🎮 Как использовать

### Для разработки - Демо вход

1. **Откройте сайт** `http://localhost:5174`
2. **Нажмите кнопку "Вход"** в правом верхнем углу 
   - 🎨 Красивая синяя обводка в стиле сайта
3. **Откроется модальное окно** с:
   - ✨ Анимированным фоном с частицами (как на главной странице)
   - 🎭 Градиентным заголовком
   - 🔵 Синей обводкой для консистентности дизайна
4. **Нажмите "Демо вход"** - готово!
5. **Вы залогинены!** 🎉
6. **Нажмите на аватар** → "Профиль" для просмотра вашего профиля

### Основные возможности авторизации

- ✅ **Демо режим** - работает без Telegram бота для разработки
- 🔐 **Реальный Telegram OAuth** - подключите свой бот для production
- 👤 **Профиль пользователя** - статистика, достижения, прогресс
- 🎨 **Красивый UI** - синяя обводка, анимированный фон, темная тема
- ⚡ **Быстрая авторизация** - одноклик вход

### Как переключиться на реальный Telegram бот

1. Получите токен от `@BotFather` в Telegram
2. Добавьте токен в `.env` файл бэка:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
   ```
3. Замените `YOUR_BOT_USERNAME` на ваш username в `src/components/LoginModal.tsx`
4. Перезагрузите приложение

## 🔧 Переменные окружения

**Frontend (.env в корне):**
```
VITE_API_URL=http://localhost:8001
VITE_TELEGRAM_BOT_USERNAME=your_bot_username
```

**Backend (ai-chat-microservice/.env):**
```
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=texel_learning

TELEGRAM_BOT_TOKEN=your_token (опционально для демо)
JWT_SECRET_KEY=your_secret_key_min_32_chars
```

## ❓ Проблемы?

### "Cannot find module"
```bash
npm install  # переустановите зависимости
```

### "Connection refused"
- Проверьте что backend запущен на `http://localhost:8001`
- Проверьте VITE_API_URL в .env фронта

### Ошибки БД
- Убедитесь MySQL запущен
- Проверьте пароль в .env
- Запустите импорт schema еще раз
