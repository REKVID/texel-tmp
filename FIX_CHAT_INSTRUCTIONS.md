# 🔧 Инструкция: Исправление чата на странице "Обучение"

## 🎯 Проблема
Чат не работает на странице обучения из-за отсутствия настроек и микросервиса.

## ✅ Быстрое решение

### Шаг 1: Получение API ключа OpenRouter

1. Зайдите на [https://openrouter.ai/](https://openrouter.ai/)
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел "API Keys" (нажмите на свой профиль → Keys)
4. Создайте новый ключ или скопируйте существующий
5. **Скопируйте ключ** - он понадобится в следующем шаге

### Шаг 2: Настройка микросервиса

Откройте файл `ai-chat-microservice\.env` и замените `your_api_key_here` на ваш реальный ключ:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш-реальный-ключ-здесь
```

### Шаг 3: Запуск микросервиса

Откройте терминал и выполните:

```bash
# Переход в папку микросервиса
cd ai-chat-microservice

# Установка зависимостей (если еще не установлены)
pip install -r requirements.txt

# Запуск микросервиса
python run.py
```

Вы увидите:
```
🤖 AI Chat Microservice starting...
INFO:     Uvicorn running on http://0.0.0.0:8001
```

**Оставьте это окно открытым!** Микросервис должен работать.

### Шаг 4: Запуск фронтенда

Откройте **новый терминал** и выполните:

```bash
# В корне проекта
npm run dev
```

Фронтенд запустится на http://localhost:8080

### Шаг 5: Проверка работы

1. Откройте браузер: http://localhost:8080
2. Перейдите на страницу "Обучение"
3. Нажмите на кнопку чата в правом нижнем углу
4. Задайте вопрос (например: "Что такое Python?")
5. Получите ответ от ИИ! ✨

## 🔍 Если чат все еще не работает

### Проверка 1: Микросервис работает?

Откройте в браузере: http://localhost:8001/health

Должно показать:
```json
{
  "status": "healthy",
  "version": "1.0.0"
}
```

Если показывает ошибку - микросервис не запущен.

### Проверка 2: API ключ настроен?

Проверьте в терминале, где запущен микросервис. Должна быть строка:
```
OpenRouter API Key configured: YES
```

Если написано `NO` - API ключ не установлен в `.env` файле.

### Проверка 3: Переменные окружения фронтенда

Убедитесь, что файл `.env` в корне проекта содержит:
```
VITE_AI_CHAT_API_URL=http://localhost:8001
```

Если этого файла нет или он изменен - перезапустите фронтенд (`Ctrl+C` и снова `npm run dev`).

## 📝 Альтернативный запуск через Docker

Если у вас установлен Docker, можно использовать более простой способ:

```bash
# В папке ai-chat-microservice
# Сначала добавьте API ключ в .env файл
docker-compose up --build
```

## ❓ Частые проблемы

### Ошибка "Failed to fetch"
- ✅ Микросервис не запущен - запустите его
- ✅ Неправильный URL - проверьте `.env` файл
- ✅ Firewall блокирует - отключите временно

### Ошибка "API key not configured"
- ✅ Не добавлен ключ в `.env` - добавьте его
- ✅ Некорректный формат ключа - проверьте, начинается ли с `sk-or-v1-`

### Чат открывается, но не отвечает
- ✅ API ключ недействительный - проверьте на openrouter.ai
- ✅ Закончился кредит на аккаунте OpenRouter - пополните баланс

## 🎉 Готово!

Теперь чат должен работать. Если возникнут проблемы - проверьте логи в терминале микросервиса.
