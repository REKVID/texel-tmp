# 🔄 Выделение ИИ Микросервиса

Микросервис для ИИ чатов теперь **полностью независим** и находится в отдельной папке `ai-chat-microservice/`.

## 📂 Что изменилось

### ✅ Создана отдельная папка микросервиса

```
ai-chat-microservice/          # 🆕 Независимый микросервис
├── app/
│   ├── __init__.py
│   └── main.py               # FastAPI приложение (улучшенная версия)
├── requirements.txt          # Python зависимости
├── README.md                 # Подробная документация
├── Dockerfile               # Docker образ
├── docker-compose.yml       # Docker Compose для деплоя
├── run.py                   # 🚀 Скрипт быстрого запуска
├── env.example              # Пример конфигурации
└── .gitignore              # Игнорируемые файлы
```

### ❌ Удален старый файл

- `ai-chat-microservice-example.py` → **удален** (заменен структурированным проектом)

## 🚀 Как запускать микросервис

### Вариант 1: Быстрый запуск (рекомендуется)

```bash
cd ai-chat-microservice
python run.py
```

Скрипт `run.py` автоматически:
- ✅ Проверяет версию Python (3.8+)
- ✅ Создает .env из примера
- ✅ Устанавливает зависимости
- ✅ Запускает сервис с hot-reload

### Вариант 2: Ручная настройка

```bash
cd ai-chat-microservice

# Установка зависимостей
pip install -r requirements.txt

# Настройка конфигурации
cp env.example .env
nano .env  # добавьте ваш OPENROUTER_API_KEY

# Запуск
python app/main.py
```

### Вариант 3: Docker

```bash
cd ai-chat-microservice

# Docker Compose (рекомендуется)
docker-compose up --build

# Или обычный Docker
docker build -t ai-chat-service .
docker run -p 8001:8001 -e OPENROUTER_API_KEY=your_key ai-chat-service
```

## 🔗 Интеграция с фронтендом

Фронтенд настроен на работу с микросервисом по адресу `http://localhost:8001`.

### Настройка во фронтенде:

```typescript
// src/services/aiChatApi.ts
const AI_CHAT_API_URL = import.meta.env.VITE_AI_CHAT_API_URL || 'http://localhost:8001';
```

### Переменные окружения фронтенда:

```env
# .env во фронтенде
VITE_AI_CHAT_API_URL=http://localhost:8001
```

## 🚀 Преимущества разделения
